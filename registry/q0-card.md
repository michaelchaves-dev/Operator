# Q0 card

Before tool selection. Closed answers only. Agent asks zero open-ended questions.

WHAT — topic already in the turn, or list at most three letters
WHERE — A chat  B repo  C Drive  D phone  E other
DO — A write  B read  C brainstorm (no write)  D status
WHEN — A now  B later  C skip
PARTICULAR — A none  B one named constraint

After the card: zero-shot with bans + schema. Tool only if DO is B, D, or named write with WHEN A. No suggestion menu.
